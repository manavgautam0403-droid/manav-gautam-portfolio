# Manav Gautam Portfolio

Create a modern, professional, and responsive personal portfolio website for Manav Gautam, a first-year B.Tech CSE (Core) student at JECRC University, Jaipur.

Use a premium dark navy blue theme with white text, cyan accents, clean typography, and minimal animations.

Include these sections:

1. Home: Name, professional introduction, profile photo placeholder, and contact button.

2. About: Passionate about technology, innovation, entrepreneurship, and learning software development.

3. Education: B.Tech CSE at JECRC University (2026–Present), Class 12 from SVVM Public School (2026), and Class 10 (2024).

4. Interests: Web Development, AI, Entrepreneurship, Cricket, and Aviation.

5. Projects: FitPulse, an AI-powered fitness platform concept.

6. Contact: Email, GitHub, and LinkedIn placeholders.

Use React, TypeScript, and Tailwind CSS. Make it visually attractive but lightweight, with smooth navigation and simple hover effects.

Avoid heavy animations, 3D effects, databases, and unnecessary features. Do not invent technical skills or achievements.

Build the complete single-page website in one attempt, ready for preview and publishing.
